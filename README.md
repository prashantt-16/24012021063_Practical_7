# MAD Practical 7 – RecyclerView

## Aim
To develop an Android application that demonstrates displaying a list of items using `RecyclerView`.

## Overview
This Android Studio project is for MAD Practical 7. It uses Android's `RecyclerView` to display a scrollable list of items efficiently. The list layout is managed with `LinearLayoutManager`, and View Binding can be used to access layout views safely.

> Update this README if your practical implements a different specific list or item design.

## Technologies Used
- Android Studio
- Kotlin
- XML layouts
- Android SDK
- Gradle
- RecyclerView
- View Binding (if enabled in the project)

## Project Structure
- `app/` — application source code and resources
- `gradle/` — Gradle wrapper configuration
- `build.gradle.kts` — project-level Gradle configuration
- `settings.gradle.kts` — project settings

## How to Run
1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle sync to finish.
4. Start an Android emulator or connect an Android device with USB debugging enabled.
5. Click **Run** to build and launch the application.

## Concepts Demonstrated
- Setting up a `RecyclerView`
- Using `LinearLayoutManager` to arrange items vertically
- Connecting list data to a RecyclerView adapter
- Using View Binding, if configured
- Building and running an Android application

## Expected Outcome
The application launches successfully and displays its list of items in a scrollable RecyclerView.

## Learning Outcome
This practical provides experience with displaying collections of data in Android using RecyclerView and managing list layout with a layout manager.
